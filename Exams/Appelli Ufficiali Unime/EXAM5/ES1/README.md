# Esercizio 1 (5 Punti) - Classi Astratte e Polimorfismo


1. Definire la classe astratta `Animale`, con il metodo astratto `verso`, che non riceve parametri e restituisce una stringa.
2. Definire le due sottoclassi `Cane` e `Gatto`, che implementano il metodo `verso` restituendo rispettivamente `bau` e `miao`.

## Output atteso

```text
Cane   ->  bau
Gatto  ->  miao
```
